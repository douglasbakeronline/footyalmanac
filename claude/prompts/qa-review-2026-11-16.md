## How to work

- Pull first; the bot commits to `main` all day.
- Run `python3 nametest.py`, `python3 -m unittest discover -s tests`, and a
  fast build (`python3 build.py --days 2 --no-topup --no-odds`); restore the
  bot-written files the build touches before committing.
- One branch and pull request per fix, each with a regression test, a
  `RELEASES.md` entry with a unique id and "(tag pending)", and the matching
  `claude/` note or CLAUDE.md line where a file's behaviour changed. Merge
  when Tests and Evaluation pass.
- Visual fixes: check at desktop and ~400 px before shipping.
